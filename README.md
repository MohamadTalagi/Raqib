# Raqib

**An Automated IoT Security Assessment and NCA Compliance Platform**

Raqib is an AI-assisted platform for assessing IoT security risks and alignment with Saudi cybersecurity guidelines. It combines automated evidence collection, deterministic policy evaluation, vulnerability intelligence, risk analysis, and explainable reporting in a centralized dashboard.

> [!IMPORTANT]
> Raqib is an **alignment and assessment tool**, not an official NCA certification platform. AI supports remediation guidance but never determines compliance verdicts.

## Compliance and Security Frameworks

Raqib is grounded in two primary frameworks:

* **NCA CGIoT-1:2024:** Implemented end-to-end as an **81-guideline compliance module**.
* **OWASP IoT Top 10:** Used to guide vulnerability detection, including:

  * Default and hard-coded credentials
  * Insecure network services
  * Insecure protocols
  * Missing or insecure update mechanisms

## Key Capabilities

### Automated Evidence Collection

A dedicated worker service collects deterministic, hashed, and reproducible evidence through:

* Network and service discovery
* Default-credential testing
* MQTT and TLS security testing
* Packet capture and traffic analysis
* Firmware SBOM generation
* CVE identification and analysis

Every assessment result retains its evidence provenance for traceability and review.

### Deterministic Compliance Evaluation

Raqib includes two centralized Python policy engines:

1. An original five-control pilot evaluator
2. A complete **CGIoT-1:2024 evaluator** covering all 81 guidelines

The engines produce explainable verdicts using the following states:

* `Pass`
* `Fail`
* `Partial`
* `Inconclusive`
* `Not Applicable`

Compliance decisions are rule-based and reproducible; they are never generated by AI.

### Dynamic Risk Assessment

A seven-factor risk engine calculates risk dynamically using collected technical evidence and vulnerability intelligence.

The platform also enriches vulnerability findings with the **CISA Known Exploited Vulnerabilities (KEV)** catalog to prioritize vulnerabilities with confirmed real-world exploitation.

### AI-Assisted Remediation

Gemini generates remediation blueprints based on identified findings. These recommendations are subject to human review and do not influence compliance verdicts directly.

### Reporting and Dashboard

Raqib provides:

* Deterministic executive summaries
* Full evidence provenance
* Exportable PDF reports
* Exportable HTML reports
* Machine-readable JSON reports
* A centralized assessment and compliance dashboard

## Simulated IoT Test Lab

Raqib was developed and validated using a Docker-based simulated IoT lab, allowing the auditor to be tested without interacting with real infrastructure.

The lab models:

* Eight devices across three security postures:

  * Insecure
  * Partially hardened
  * Hardened
* Five additional IoT device types
* Devices grounded in real, CVE-documented vendor products

> [!NOTE]
> The simulated lab is a development and verification harness only. It is not part of the production platform.

## Architecture

The platform is built using:

* **Frontend:** React
* **Backend:** FastAPI
* **Policy engines:** Python
* **Database:** PostgreSQL
* **Test environment:** Docker
* **AI assistance:** Gemini
* **Vulnerability intelligence:** CVE data and CISA KEV

## Scope and Design Principles

Raqib is designed around four core principles:

* **Deterministic:** The same evidence produces the same verdict.
* **Explainable:** Every result includes its reasoning and supporting evidence.
* **Traceable:** Collected evidence is hashed and linked to its source.
* **Human-governed:** AI-generated remediation guidance requires human review.
